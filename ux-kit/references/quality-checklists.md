# 质量检查清单

按产出模式执行对应清单。生成材料后逐项检查，不通过项标注问题并给出修改建议。

---

## 方案清单（2D）

- [ ] 每个阶段是否以数据采集方式为锚点？嵌入技术是否正确归入？
- [ ] 是否有可合并的阶段被拆开？阶段总数是否 ≤ 4？
- [ ] 六部分结构是否齐全（背景与目标/设计总览/用户与样本/具体阶段/时间计划/注意事项）？
- [ ] 设计总览是否为箭头流程图？阶段框内是否用简短方法名 + 定性/定量标注（无冗长阶段名）？
- [ ] 设计说明是否含三层：各阶段回答什么问题（简洁自拟）、方法选择理由、阶段衔接？
- [ ] 各阶段样本设计是否合并在第三部分一张表（阶段/样本量/特征/配额）？样本量按主采集方式计算？配额维度 ≤ 3？
- [ ] 阶段标题是否体现核心目标+方法？"目标"是否一句话简洁？
- [ ] 材料小节标题是否为材料名（访谈提纲/问卷/可用性测试方案/声音分析计划），内容是否为"确认后生成《××.md》，包括××模块"式内容概述？
- [ ] 实施流程及时间计划是否为阶段×事项表（含预估天数）？是否给出预计总耗时（含可并行说明）？
- [ ] 是否未在阶段内重复样本设计与实施要点？

## 问卷清单（2A / 2D 问卷阶段）

- [ ] 设计模式与模型判定是否正确（量表驱动/开放探索/方法论驱动/混合；Kano/ETS/通用）？
- [ ] 是否存在双重问题、引导性措辞、否定嵌套、假设性前提？
- [ ] 题目是否可追溯到研究目标？选项是否互斥且穷尽？多选是否标注"（可多选）"？
- [ ] Kano 正反题是否配对完整？ETS-U 的 NPS 是否为 0-10 分制？ETS-E 陈述 48 条、重要度 26 项（条数保留）？题项适配是否遵循最小改动原则（语义保真）？线下服务类自建量表是否在设计中注明理由？
- [ ] 量表驱动型是否输出了测量框架表？

## 提纲清单（2B / 2D 访谈阶段）

- [ ] 每个话题模块是否有标题 + 斜体目标 + 四列表格？
- [ ] 题目是否开放、锚定具体事件？执行要点是否白话可操作？
- [ ] 是否覆盖所有研究目标？是否含开场暖场与收尾？
- [ ] 是否存在禁忌题目（否定假设、未来预测、让用户定价/设计、双重问题）？
- [ ] 概述中是否未重复研究背景与目标/被访者画像？
- [ ] 是否未在产出中出现 CBA/JTBD/ORID 等方法标签？

## 可用性清单（2C / 2D 可用性阶段）

- [ ] 测试目标是否与任务、探寻内容有明确对应？
- [ ] 任务卡是否完整（场景/任务步骤/探寻问题/完成标准/参与者打分）？
- [ ] 任务是否以用户视角编写、避免技术语言？是否聚焦高频/新增/有疑问功能？
- [ ] 开场白是否含"评估产品而非用户能力"声明？是否含总结回顾与结束语？
- [ ] 附录是否含任务记录表？
- [ ] 涉及眼动测试时，是否参考了 eye-tracking.md 的需求编写流程？
