# 员工食堂体验研究方案

## 一、研究背景与目标

### 研究背景

公司食堂日常运营中，管理层希望了解员工就餐体验的现状与问题，以支撑食堂改进升级决策，并建立常态化的满意度监测机制。本次研究覆盖菜品质量与口味、环境与卫生、服务与流程、设施与便利性四个维度。

### 研究目标

1. 量化评估员工对食堂四个维度的满意度水平，识别薄弱环节
2. 挖掘不满意原因与具体改进点
3. 建立食堂满意度监测基线，支持后续定期追踪对比

### 核心研究问题

评估员工对食堂的就餐体验，覆盖菜品质量与口味、环境与卫生、服务与流程、设施与便利性四个维度，定位满意与不满意的具体方面与改进机会，为食堂改进升级提供方向，并建立日常满意度监测基线。

## 二、研究设计总览

```
阶段一（定性）              产出              阶段二（定量）            产出
用户访谈 ────→ 痛点与改进假设 ────→ 问卷验证 ────→ 满意度量化结论
```

**设计说明**：
- 阶段一（定性）回答「哪些地方不满意、为什么不满意」：访谈深挖不满原因与具体改进点，理解"为什么不满意"
- 阶段二（定量）回答「不满意到什么程度、哪些最要紧」：问卷量化四维度满意度水平，验证痛点普遍性并排序改进优先级
- 阶段衔接：访谈产出的痛点清单与改进假设直接转化为问卷的题项设计与选项来源

## 三、目标用户定义与样本设计

### 目标用户

- **主样本**：本公司员工，覆盖不同就餐频率（每天就餐 / 经常 / 偶尔 / 几乎不去）
- **细分维度**：就餐频率、部门/职级、就餐地点（用于分组分析）
- **排除条件**：食堂运营方人员、餐饮行业从业者

### 样本设计

| 阶段 | 样本量 | 样本特征要求 | 样本配额 |
|------|--------|-------------|---------|
| 阶段一：用户访谈 | 12 人（信息饱和原则 8-12 取上限） | 本公司员工；过去 1 个月至少到食堂就餐 1 次；排除食堂运营方/餐饮从业者 | 就餐频率：每天 5 人 / 经常 4 人 / 偶尔 3 人；部门均衡 |
| 阶段二：问卷调查 | ≥300 份有效问卷（全员开放，目标有效回收率 ≥60%） | 全体员工，含不同就餐频率、部门、就餐地点；排除食堂运营方人员 | 自然回流不强制配额；分析时按部门/就餐频率/地点分层报告（子群 ≥30 份才独立分析） |

## 四、具体研究阶段

### 阶段一：挖掘就餐痛点与改进机会（用户访谈，含灵犀旅程、JTBD）

#### 目标

定性深挖员工对食堂就餐体验的痛点与不满原因，回溯就餐全流程识别关键问题环节，探索四个维度下的具体改进机会，为问卷设计提供题目素材。

#### 访谈提纲

确认后生成《员工食堂体验访谈提纲.md》，包括：开场暖场、就餐全流程回溯（灵犀旅程：进入食堂→排队→选餐→就餐→离开）、四维度深挖（菜品质量与口味/环境与卫生/服务与流程/设施与便利性）、就餐方式选择（JTBD 决策链：食堂 vs 外卖 vs 自带）、理想形态与建议、收尾模块。

#### 预期产出

- 就餐全流程痛点清单（按旅程环节分类）
- 四维度改进机会假设（进入问卷验证）
- 就餐方式选择的原因图谱（不满却不投诉/流失的原因）

### 阶段二：量化满意度与验证改进点（问卷调查，量表驱动）

#### 目标

量化员工对食堂四个维度的满意度水平，识别薄弱环节，验证访谈发现的普遍性，建立满意度监测基线。

#### 问卷

确认后生成《员工食堂体验问卷.md》，包括：甄别题（就餐频率、就餐地点）、四维度满意度量表（菜品质量与口味/环境与卫生/服务与流程/设施与便利性，每维度 3-4 题，李克特五点）、整体评价（整体满意度、最需改进方面）、不常就餐原因、开放建议、基本信息模块。

> 兜底场景说明：食堂为线下服务类评估对象，ETS 8 维度体系（功能流程/交互设计/视觉设计等）面向标准消费者产品基本不适用，故采用自建维度量表，问卷设计说明中需注明此理由。

#### 预期产出

- 四维度满意度得分与排序（薄弱环节识别）
- 各题项满意度分布（改进点明细）
- 满意度基线数据（供后续定期监测对比）
- 访谈发现的普遍性验证结果

## 五、实施流程及时间计划

| 阶段 | 事项 | 预估时间（天） |
|------|------|--------------|
| 阶段一：用户访谈 | 按就餐频率配额招募 12 人并排期 | 3 |
| | 执行访谈（12 场，非午餐高峰时段） | 5 |
| | 逐场整理笔记与痛点归纳 | 3 |
| | 输出改进假设与问卷题目素材 | 2 |
| 阶段二：问卷调查 | 问卷定稿与预测试（5-8 人认知访谈） | 3 |
| | 内部系统匿名投放与回收 | 5 |
| | 数据清洗与统计分析 | 3 |
| | 满意度报告与改进优先级交付 | 2 |

**预计总耗时**：约 26 天（其中阶段二问卷投放可与阶段一访谈执行并行推进，实际日历周期可压缩至约 4 周）

## 六、注意事项

1. **社会期望偏差**：满意度调研易受"客气作答"影响，问卷匿名发放、题目措辞中性化；访谈中锚定具体事件交叉验证
2. **覆盖偏差**：不常去食堂的员工参与率可能偏低，其意见通过访谈阶段低频用户配额补充
3. **自评 vs 行为**：自评数据无法完全反映实际就餐行为，后续可结合食堂运营数据（消费流水、客流、菜品销量）交叉验证
4. **多地点差异**：若食堂存在多园区/楼层差异，问卷需收集就餐地点，各地点单独分析后再看整体结论
